📡 開放資料 API

整合交通部中央氣象署開放資料平台 (CWA Open Data)，支援即時 JSON 擷取與離線示範資料容錯機制。

🗺️ 地理資訊視覺化

整合 Leaflet 與 OpenStreetMap 台灣圖資，以動態溫標色階標註台灣 6 大區域並支援交互點擊彈窗。

📈 雙軌氣溫趨勢曲線

使用 Chart.js 繪製一週 MinT 與 MaxT 折線圖，具備平滑張力曲線與數值標記。

🤖 AI 智慧生活決策

根據即時溫差、均溫與高溫警示，動態運算個人化穿著建議、出遊指南與健康防護提示。
